# My-Python-Learning-Journey

## 项目简介

这个仓库目前包含两个和**心理学实验数据**相关的小程序：

- 一个用于单名被试的反应时数据录入与初步筛查；
- 一个用于多名被试连续录入反应时、自动剔除无效数据并计算平均值。

它们解决的问题很实际：手工算平均反应时比较费事，也容易把异常的数值（比如手滑敲成 5 毫秒、或者走神导致 3000 毫秒）算进结果里。程序把”录数据“和“筛数据”这两步自动化，保证每次计算的口径一致。

## 文件说明

| 文件名                    | 用途                                            |
| ---------------------- | --------------------------------------------- |
| `reaction_average.py`  | 连续录入 6 次反应时，自动跳过异常值，最后输出有效数据个数和平均反应时。         |
| `reactiontime_test.py` | 录入单名被试的编号、年龄和 3 次反应时，计算平均反应时、极差，并判断该被试数据是否有效。 |

## 使用方法

需要 Python 3，不需要安装任何第三方库。在命令行中进入仓库目录后运行：

```bash
python reaction_average.py
python reactiontime_test.py
```

程序运行后会按提示依次输入数据，回车确认即可。

## 代码说明

### reaction_average.py —— 带异常值剔除的平均反应时

核心思路是：先准备好三个变量作为容器，然后在循环里一边录入一边累加。

```python
times = 0         # 已录入次数
valid_count = 0   # 有效数据数量
total = 0         # 有效反应时的总和

while times < 6:
    reaction_time = float(input("请输入第" + str(times + 1) + "次反应时（毫秒）"))
    times += 1    # 每次输入都计数，包括无效数据
    if reaction_time < 100 or reaction_time > 1500:
        print("本次数据无效，跳过统计")
        continue
    valid_count += 1
    total += reaction_time
```

几个关键点：

- **`times` 与 `valid_count` 分开计数**：`times` 控制循环次数（保证一定问 6 次），`valid_count` 只统计有效数据。如果用一个变量同时干这两件事，遇到无效数据时循环次数就会乱。
- **`continue` 的作用**：一旦判定为异常值，直接跳过本轮剩下两行累加语句，回到循环开头。这比把累加代码再包一层 `if` 更扁平、更好读。
- **除法保护**：6 次数据可能全都无效，此时 `total / valid_count` 会报除零错误，所以先用 `if valid_count > 0` 判断，否则输出「没有有效数据」。

```python
if valid_count > 0:
    average = total / valid_count
    print("平均反应时:" + str(average) + "毫秒")
else:
    print("没有有效数据")
```

### reactiontime_test.py —— 单被试数据有效性判断

先录入数据，再一次性算出平均反应时、极差和秒制换算值：

```python
mean_rt = (rt1 + rt2 + rt3) / 3
range_rt = max(rt1, rt2, rt3) - min(rt1, rt2, rt3)
mean_rt_sec = mean_rt / 1000
```

**极差**用「最大值减最小值」实现，借用了内置函数 `max()` 和 `min()`，不必手写比较。

有效性判断用了一条链式比较，把三个条件用 `and` 串起来，全部满足才算有效：

```python
is_valid = (18 <= age <= 35) and (200 <= mean_rt <= 1000) and (range_rt < 300)
```

- `18 <= age <= 35` 是 Python 特有的写法，等价于 `age >= 18 and age <= 35`，边界值 18 和 35 都算通过。
- 三个条件分别对应：年龄在实验要求的范围内、平均反应时没有快到不合常理也没有慢到疑似走神、三次数据之间波动不过大（极差小于 300 毫秒）。

`is_valid` 存的是一个布尔值（`True` / `False`），输出时用 `str()` 转成字符串再拼接到提示语后面。

## 学习心得与规划

浏览 GitHub 上其他人的 Python 项目，最直观的感受是：能看懂的项目，几乎都是先说清程序解决什么问题，再列文件，最后才给出代码。而我之前只是把 `.py` 文件丢进仓库，别人打开可能就会对着两个文件名不知所措。这让我意识到，管理个人项目和整理实验数据是一回事：命名、说明、归类本身也是工作的一部分。

写这份 README 时，我回头重读了自己的代码，才发现 `times`、`total` 这类变量名脱离上下文并不好懂，于是补了注释。

启发有两点：一是仓库不只是交作业的地方，它是技能的一个记录，像上课做的手写笔记一样。二是文档要趁热写，隔久了就不知道怎么写了。

规划：每设计一个心理学实验相关的统计或者实验程序就往仓库里加一个 `.py` 文件，并同步更新本 README；按主题分目录（如 `basics/`、`loops/`、`functions/`）；每次提交写清改了什么；学期末把零散练习整理成一两个有实际功能的小工具，比如批量汇总多名被试反应时的分析脚本。
